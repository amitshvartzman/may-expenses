# מעקב הוצאות- מאי

אתר סטטי אחד (`index.html`) שמאוחסן ב־GitHub Pages ושומר את הנתונים ב־Supabase.

## איך זה עובד
- אין התחברות. הכניסה היא בקישור אישי שבסופו `#k=` ומפתח סודי ארוך.
- המפתח לא נשלח לשום שרת אחסון ולא נשמר בקוד. במסד הנתונים נשמר רק ה־hash שלו.
- הטבלאות סגורות לגישה ישירה. כל קריאה וכתיבה עוברות דרך פונקציות ב־`supabase/setup.sql` שבודקות את המפתח.
- כל שינוי נשמר קודם בדפדפן ונשלח לענן. אם אין חיבור, הוא נשלח כשהחיבור חוזר.
- `.github/workflows/keepalive.yml` שולח ל־Supabase בקשה כל יום, כדי שהפרויקט החינמי לא יוקפא.

## קבצים
- `index.html`: האפליקציה.
- `config.js`: כתובת הפרויקט ב־Supabase והמפתח הציבורי (publishable). שניהם ציבוריים מעצם הגדרתם.
- `supabase/setup.sql`: טבלאות, הרשאות ופונקציות. מריצים פעם אחת ב־SQL Editor.
- `secret-keys.local.json` ו־`MAY-LINK.txt`: המפתחות הסודיים והקישורים. נשארים רק במחשב הזה, ולא עולים ל־GitHub (`.gitignore`).

## שני ארנקים
- `may`: הקישור של מאי.
- `test`: קישור לבדיקות, כדי לנסות דברים בלי לגעת בנתונים של מאי.
